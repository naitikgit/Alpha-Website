# Alpha Automation website

A responsive five-page website concept for Alpha Automation, built in plain HTML, CSS and JavaScript.

## Pages

- `index.html` — Home
- `products.html` — Searchable, filterable product categories
- `services.html` — Automotive service overview
- `about.html` — Brand story
- `contact.html` — Enquiry form and FAQs

## Preview

Open `index.html` in a browser, or run a local server from this folder, for example:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing

The contact section and page footers include clickable call, email and WhatsApp details. Verify these details before publishing. Add your business address and opening hours, and review the sample product categories against the current catalogue. The website uses locally stored generated automotive photographs.

The site uses Google Fonts when a network connection is available and falls back to system sans-serif fonts.
